ILLUSTRATIVE BRIEF / WEB DEVELOPMENT

Help students find
the right resource.

Design and build a campus resource finder that makes useful notes easier to discover by subject, branch and semester.

Level: Beginner to intermediate
Skills: HTML/CSS, JavaScript or React, search UX, APIs
Suggested team: Developer + Designer • planning guidance only
Express teammate interest

What you'll build:

  • ✓ Search and filters with clear empty states
  • ✓ Accessible resource cards and detail view
  • ✓ A sample dataset with honest availability labels
  • ✓ README, screenshots and a short reflection
Stretch goal: Add a missing-resource request flow with friendly modal feedback.
