FEATURED ROADMAP • WEB DEVELOPMENT

From your first webpage
to a full-stack application.

Understand the browser, build responsive interfaces, connect real data and learn to deploy. Each stage ends in something you can make.

Enquire about this path

Overview & Prerequisites

Prerequisites: A laptop, basic computer familiarity and curiosity. No coding experience required.

Suggested pace: 12–16 weeks • illustrative planning guidance

Outcomes: A responsive site, a data-powered app and a documented portfolio project.

01

HTML & CSS

Semantic structure, layouts, responsive design.

▸ Build a personal homepage
02

JavaScript

Logic, DOM manipulation, events and async fetch calls.

▸ Make an interactive quiz app
03

Frontend & APIs

React, state hooks, accessibility and real REST APIs.

▸ Build a campus resource finder
04

Backend & Deploy

Node.js, PostgreSQL/MongoDB, cloud deployment & CI/CD.

▸ Ship a full-stack project
